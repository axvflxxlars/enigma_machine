# data/

Сюди потрібно покласти два файли з англійськими n-грамами (це завдання B):

- `english_bigrams.txt`
- `english_trigrams.txt`

Формат: один рядок на n-граму, великі літери, пробіл, кількість:

```
TH 116997844
HE 100689263
...
```

Де взяти:

- Готові таблиці «english bigrams / trigrams» з practicalcryptography.com, у них саме такий формат.
- Або порахувати самостійно з великого англійського тексту (кілька книжок з Project Gutenberg, щонайменше ~1 МБ тексту). Для цього вистачить невеликого скрипта або окремої C-програми.

Перевірка: `make test` має проходити `test_ngrams` у `tests/test_score.c`.
